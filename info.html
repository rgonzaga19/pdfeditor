Privacy Policy

🔒   Your files never leave your device. All PDF processing runs entirely in your browser - no uploads, no servers, no cloud.

📂   File Handling

When you open a PDF in PDF Editor, the file is read directly by your browser using the built-in File API. It is processed in memory using PDF.js and pdf-lib - open-source libraries that run locally in your browser. The PDF file itself is never transmitted over the internet.

☷   Data Storage

  • No cookies are set by this application.
  • No local storage or session storage is used to persist your files.
  • File data and edits are held in memory and discarded when you close or refresh the tab.
  • No analytics or tracking tools are included to collect your behaviour.

🌐   Third-party Resources

This app loads fonts from Google Fonts and the PDF.js and pdf-lib libraries from cdnjs. These resources are downloaded by your browser; those requests do not include your PDF content. If you prefer full offline use, these resources can be self-hosted.
